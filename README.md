# 超音波を用いたスマートフォンによる双方向型の教室出欠システム

信号処理 自由課題（上級者向けの単位取得法）の成果物一式です。

スマートフォンのスピーカーとマイクだけを使い、人に聞こえにくい 18〜19.4 kHz の音で通信して、教室の出欠をとります。教員の端末が出席コードを流し、学生のスマートフォンが学籍番号を音で返します。返信が衝突した場合は、教員の端末がスロット数を自動で調整し、届かなかった学生だけが送り直します。

| ページ | 内容 |
|---|---|
| Step1 送信側・受信側 | 18,750 Hz の単音の送受信 |

| Step3 `step3.html` | 超音波による出欠（スロット付きALOHAとスロット数の自動制御） |

ブラウザだけで動作し、サーバーは使いません。マイクを使うため、https のページで開いてください。

## シミュレーションの実行方法

Node.js で実行できます。

```
node test.js
node compare.js
node voice.js
node attend-sim.js
```
